# Bulk Image Generator

A Chrome extension for generating multiple images using Google Flow.

## Installation

1. Download this repository:
   - Click Code
   - Click Download ZIP

2. Extract the ZIP file.

3. Open Chrome and go to:
   chrome://extensions

4. Turn ON Developer mode.

5. Click Load unpacked.

6. Open the extracted folder:
   bulk image generator

7. Select the folder containing manifest.json.

8. The extension will now appear in Chrome.

## Usage

1. Open Google Flow.
2. Open the Bulk Image Generator extension.
3. Upload your prompts file.
4. Follow the instructions in the extension.
